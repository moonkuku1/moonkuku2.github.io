# AI 연결 방법 (키를 받은 뒤)

AI 키가 없으면 사이트는 "샘플 문장 모드"로 동작합니다. 키를 넣으면 무료 사주 카드의 키워드 문장과 질문 풀이 문장이 AI로 바뀝니다. 판정·시기·확신도는 어느 쪽이든 코드가 정합니다.

## 1. 환경변수 (이름은 `.env.example`에 있습니다)

| 이름 | 뜻 | 예 |
|---|---|---|
| `LLM_PROVIDER` | AI 회사 | `anthropic`, `openai`, `google` 중 하나 |
| `LLM_MODEL` | 모델 이름 | 각 회사 문서에 적힌 정확한 이름. 비교해서 정합니다 |
| `LLM_API_KEY` | 키 | 채팅이나 GitHub에 올리지 않습니다 |
| `LLM_DAILY_CAP` | 하루 AI 호출 한도 | 처음엔 `100` 정도로 작게 |
| `CACHE_HASH_SECRET` | 캐시 키에 섞는 비밀 값 | 길고 무작위인 글자 (예: 비밀번호 생성기로 40자) |
| `PAYMENT_MODE` | `test`로 두면 질문 풀이(`/api/answer`)가 열림 | 결제 확인을 붙이면 없앱니다 |
| `OPERATOR_WEBHOOK_URL` | 답변 생성 실패 알림 주소(선택) | 슬랙 등의 수신 주소 |

- 내 컴퓨터에서 시험할 때: 프로젝트 맨 위 폴더의 `.env.local`에 한 줄씩 적습니다.
- 배포 사이트에서 쓸 때: Vercel → 프로젝트 → Settings → Environment Variables에 같은 이름으로 넣고 Redeploy 합니다.

## 2. 꼭 함께 해야 할 비용 안전장치
- `LLM_DAILY_CAP`은 서버 한 대 안에서만 셉니다. Vercel은 서버가 여러 대로 나뉠 수 있어서 진짜 상한이 아닙니다.
- **AI 회사 콘솔에서 월 사용 한도(예산 한도, 사용량 알림)를 꼭 거세요.** 이것이 실제 상한입니다.
- 무료 사주 카드는 명식당 AI를 한 번만 부르지만, 서버가 다시 시작되면 저장소가 비어 같은 사람이 다시 부를 수 있습니다. 결과 저장소(Supabase)를 붙이면 해결됩니다.

## 3. 확인하는 방법
1. 키를 넣고 사이트에서 생년월일을 넣어 카드를 만듭니다. 카드 아래의 "샘플 문장이에요" 안내가 사라지면 AI가 쓴 문장입니다.
2. AI 답이 검수에 떨어지거나 한도에 걸리면 자동으로 샘플 문장으로 보여 줍니다(무료 카드). 서버 로그에 `[프로필 문장 오류]`가 남습니다.
3. 이용 흐름 기록은 Vercel Logs에서 `[event]`로 검색합니다(카드 생성, 질문 담기 등. 개인정보 없음).

## 4. 아직 하지 않은 것
- 모델 비교(질문 20개로 통과율·말투·비용 확인)와 모델 확정 (`tasks.md` 19-9)
- 결과 저장소와 로그인 (Supabase)

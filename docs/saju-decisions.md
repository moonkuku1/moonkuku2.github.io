# 사주 계산 규칙: 정해야 할 것과 지금 쓰는 값

만세력 계산(`lib/saju`)에서 유파·만세력마다 달라지는 부분입니다. "지금 쓰는 값"은 코드에 들어 있는 기본값이고, 명리 전문가 검수(요구사항 "코드 밖에서 할 일") 때 함께 확인합니다.

## 2. 유파마다 갈리는 세 가지: 추천안 A로 확정해서 구현함 (2026-11-14, 사장님 결정)

세 가지는 판정법이 유파마다 크게 달라 선택지를 정리했고, 사장님이 모두 **추천안(A)**으로 정했습니다. 아래 표의 굵은 줄이 구현된 방식이며, 기준값은 코드 한 곳(`STRENGTH_THRESHOLDS` 등)에서 고칠 수 있습니다. 명리 전문가 검수 후 바뀔 수 있습니다.

- 신강·신약: `lib/saju/analysis/strength.ts` (자리별 점수. 극신약 25% 미만 / 신약 45% 미만 / 중화 55% 이하 / 신강 75% 미만 / 극신강 75% 이상)
- 격국: `lib/saju/analysis/structure.ts` (월지 본기 기준 11가지)
- 도움이 되는 오행: `lib/saju/analysis/yongshin.ts` (억부 + 조후 단순형, 조후는 해·자·축월에 화, 사·오·미월에 수)

### 2-1. 신강·신약 (일간이 강한가, 약한가)

| 방식 | 내용 | 장단점 |
|---|---|---|
| **A. 자리별 점수 (추천)** | 월지(월령)에 가장 큰 점수(3), 일지 2, 나머지 글자 1점씩 해서 총 10점. 일간을 돕는 글자(비견·겁재·편인·정인)의 점수 비율로 5단계(극신약·신약·중화·신강·극신강) | 근거가 눈에 보이고 설명하기 쉬움. 월령 중심이라 전통 이론과 잘 맞음 |
| B. 오행 세력 비교 | 오행 분포(지장간 포함)로 돕는 오행과 빼는 오행의 합을 비교 | 가장 단순. 계절·위치 영향은 무시 |
| C. 12운성 사용 | 일간이 월지·일지에서 어떤 운성(장생·제왕 등)인지 | 전통적이나 계산·설명이 복잡 |

### 2-2. 격국 (사주의 틀)

| 방식 | 내용 | 장단점 |
|---|---|---|
| **A. 월지 본기 기준 (추천)** | 월지 본기가 일간에게 무슨 십성인지로 정관격·편관격·정인격·편인격·식신격·상관격·정재격·편재격을 정함. 월지가 비견이면 건록격, 양간의 겁재면 양인격, 음간이면 월겁격 | 간단하고 설명 가능. 투출·종격은 따지지 않음 |
| B. 투출 반영 | 월지 지장간 중 천간에 드러난(투출) 것을 우선 | 『자평진전』식. 더 정확하지만 예외가 많음 |
| C. 종격·화격 포함 | 일간이 극도로 약하거나 합화하는 특수 사주를 따로 분류 | 정확하나 판정이 복잡하고 논쟁이 많음. 오픈 초기에는 비추천 |

### 2-3. 용신 (도움이 되는 오행)

용신은 판정자에 따라 결과가 가장 많이 갈리고, 사람에게 "당신의 용신은 ○○"이라고 단정하기 쉬운 항목입니다.

| 방식 | 내용 | 장단점 |
|---|---|---|
| **A. 억부 + 조후 단순형 (추천)** | 신강이면 설기·제압하는 오행, 신약이면 생조하는 오행을 우선하고, 한여름·한겨울 출생이면 식혀 주거나 데워 주는 오행을 보정. 결과는 "도움이 되는 오행 / 조심할 오행"으로 표시 | 코드로 설명 가능. 화면에는 "용신"이라는 단정 대신 "도움이 되는 오행"이라는 표현 권장 |
| B. 통관·병약 포함 | 오행이 서로 싸울 때 중재하는 오행, 사주의 병을 고치는 오행까지 | 정확도는 높으나 규칙이 많고 전문가마다 다름 |
| C. 용신을 쓰지 않음 | 부족·과다한 오행만 보여 줌 | 가장 안전. 질문 답변(시기 판정)에 쓸 근거가 약해짐 |

레시피(요구사항 2장)의 신호 중 "용신 오행이 들어오는 달" 같은 항목이 많아서, 판정 엔진에 가기 전에 2-1~2-3을 정해야 합니다.

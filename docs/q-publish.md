# 질문 소개 페이지 공개 방법 (검색에 나오게 하기)

질문 소개 페이지(`/q/L04` 같은 주소)는 240개 질문 모두에 만들어져 있지만, **처음에는 전부 검색에 나오지 않아요**(`noindex`).
사람이 읽어 보고 괜찮다고 한 질문만 검색에 공개해요.

## 순서
1. 사이트에서 `/q/질문번호`를 열어 아래 점검표로 읽어 봐요. (예: `/q/L04`)
2. 괜찮으면 `data/q-published.json`에 질문 번호를 따옴표로 적어요.
   ```json
   ["L04", "L05", "M01"]
   ```
3. 저장하고 GitHub에 올리면(푸시) 그 질문만 검색 대상이 되고, `/sitemap.xml`에도 들어가요.
4. 되돌리려면 목록에서 번호를 지우면 돼요.

## 점검표
- 첫 줄의 질문 제목과 설명이 자연스러운가요?
- "사주에서는 이렇게 봐요"에 나온 신호 설명이 그 질문과 어울리나요? (명리 전문가 검수 권장)
- 겁주는 말, 단정하는 말, 건강·투자·법률 판단이 없나요?
- 가짜 후기·이용 수·적중률 같은 숫자가 없나요? (코드가 만든 글이라 없지만 한 번 더 확인)
- 개인 사주 풀이처럼 읽히지 않나요? (이 글은 "사주에서 이 질문을 어떻게 보는가"를 설명하는 글이에요)

## 참고
- 목록에 없는 번호를 적으면 테스트(`npm test`)가 실패해서 오타를 막아 줘요.
- 글은 질문 데이터(`data/questions.json`)와 레시피의 신호 설명으로 코드가 만들어요. AI 문장(P6)은 아직 쓰지 않아요. AI 키가 생기면 P6로 더 풍부한 글을 만들고 같은 방식으로 검토해요.

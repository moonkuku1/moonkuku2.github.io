# 사주300 디자인 전달서 (Kiro용)

2026-11-14

## 요약

사주300은 **남색 달밤 민화 톤**에, 해치 삼백이와 두 풀이꾼(삼백 도령·삼백 아씨)이 질문을 맡아 **결론부터** 답하는 휴대폰 우선 사이트예요. 이 문서는 디자인 시안(Claude 디자인 캔버스 "사주300 브랜드 시안")을 Kiro가 실제 코드로 옮길 수 있게 정리한 것이에요.

- **기준 시안**: 캔버스 맨 왼쪽의 "모바일 홈", "결과 화면 (새 톤)", "공유 카드" 3종. 나머지 보드는 지난 시안이라 참고하지 않아요.
- **원칙**: 가짜 후기·구매 수·BEST 표시는 넣지 않아요. 실제 데이터가 생긴 뒤에만 써요.
- **그림 파일**: "사주300_그림파일.zip"에 모두 들어 있고, 파일 이름과 쓰임은 아래 ‘그림 파일’ 절에 있어요.

## 캐릭터 역할과 말투

세 캐릭터는 ‘해치 삼백이가 둔갑한 얼굴’이고, 질문마다 담당 풀이꾼이 정해져 있어요. 모두 “삼백” 메달을 걸어요.

| 캐릭터 | 담당 | 말투 | 예시 대사 |
| --- | --- | --- | --- |
| 삼백 아씨 | 연애 · 결혼 · 궁합 | 다정한 “~해요” | “좋아하는지 아닌지, 첫 줄에 말해 줄게요.” |
| 삼백 도령 | 일 · 재물 · 시험 · 가족 | 점잖은 “~습니다 / ~지요” | “버틸지 그만둘지, 도장 찍어 드립니다.” |
| 해치 삼백이 | 판정 도장 · 오늘 한 마디 · 올해 · 나 | 옛말투 반말 | “오늘의 한 줄은 그냥 주마. 생일만 알려 다오.” |

해치 포즈는 판정 분위기에 따라 바꿔요: 좋은 판정은 손 흔드는 해치, 조심 판정은 턱 괴고 고민하는 해치, 판정 순간은 도장 찍는 해치.

## 화면 구성

모든 화면은 **휴대폰 너비 390px 기준**, 최대 480px 가운데 정렬이에요. 컴퓨터에서는 같은 화면을 가운데에 놓아요.

### 모바일 홈 (위에서 아래)

1. **위쪽 고정 헤더**: 해치 얼굴 로고 + “사주300”, 장바구니(담은 개수 배지). 아래에 탭: 오늘 · 이럴 때 · 고민별 · 풀이꾼 · 무료
2. **풀이꾼 배너 3장** (옆으로 넘기기, 3:4, 화면 너비 86%): 그림 아래 40%에 담당 · 대사 · 가격 · 버튼
3. **해치의 오늘 한 마디** (무료): 년·월·일 선택 → 한지 카드에 한 줄 + ‘今日’ 도장 + 300원 질문으로 이어지는 링크
4. **이럴 땐 이 질문**: 상황 카드 5장 (옆으로 넘기기). 카드마다 300원 질문 3개, 질문 옆에 담당 얼굴 + ‘+’ 담기 버튼(44px)
5. **고민별 질문 30개씩**: 포스터 8장, 2열. 포스터 = 배경 그림 + 소재 그림 + 왼쪽 위 카테고리 표 + 오른쪽 위 담당 얼굴 + 아래 제목·가격
6. **사주300의 풀이꾼**: 장면 그림 카드 3장
7. **300원이면 이렇게 받아요**: 답변 예시 한지 카드
8. **무료 일주 카드 바로가기**, **사주300의 약속 3가지**, 바닥글
9. **아래 고정 메뉴**: 홈 · 오늘 한 마디 · 내 풀이함 · 내 정보. 질문을 담으면 그 위에 “담은 질문 N개 · 합계 · 결제하고 바로 보기” 줄이 떠요.

### 결과 화면 (위에서 아래)

1. **헤더**: ← 내 풀이함
2. **풀이꾼 장면**(300px) 위에 “OO의 풀이 · 카테고리”, 질문, 생년월일 정보
3. **판정 카드**(한지): 첫 줄 결론 + 판정 도장(열릴 때 찍히는 움직임) + 좋은/조심 흐름 표시 + 확신도 3단계 + 두 줄 요약
4. **언제가 좋을까**: 12달 막대. 좋은 달 금색+★, 조심할 달 붉은색
5. **이렇게 본 근거**: 명식 8글자(오행 색), 판정에 쓴 글자는 금색 테두리, 근거 3줄
6. **솔직히 말하면**: 불리한 신호 한 줄 (붉은 상자)
7. **이번 달 처방**: 할 일 하나 + 해치
8. **이어서 물어보기**: 같은 풀이꾼의 다음 질문 3개 + 담기
9. **아래 고정 버튼**: 판정 카드 공유 / 다른 질문 고르기(담으면 “N개 · 금액 결제”)

### 공유 카드

- **스토리용** 1080×1920(시안은 540×960): 풀이꾼 장면 → 한지 판정 카드 → 이번 달 처방 + 해치 → “질문 하나에 300원, 결론부터”. 서버에서 이미지로 만들어 저장 버튼 제공
- **링크 미리보기(OG 이미지)** 1200×630(시안은 600×315): 왼쪽 판정 문장, 오른쪽 풀이꾼, 아래 도장. 생년월일 같은 개인정보는 넣지 않아요.

## 부품 규칙과 문구 규칙

### 부품

- **눌러서 반응하는 모든 것은 44×44px 이상.** 눌렀을 때 0.98배로 살짝 줄어들어요.
- **담기 버튼**: 빈 동그라미 ‘+’ → 담기면 금색 채움 ‘✓’. `aria-pressed`로 상태를 알려요.
- **카드 테두리**는 1px, 금색 또는 한지색을 아주 옅게(0.1~0.35). 두꺼운 테두리나 빗긴 그림자는 쓰지 않아요.
- **한지 카드**는 안쪽 7~9px에 금선 한 줄(outline + outline-offset).
- **판정 도장**: 判定三百 2×2 배치, -8도 기울임, 붉은 테두리.
- **움직임**은 도장 찍히기 하나에만. `prefers-reduced-motion`이면 끕니다.
- 설명이 필요한 그림에는 `alt`, 꾸밈 그림은 `alt=""`.

### 문구

- **‘돈’ 대신 ‘재물’.** (재물운, 재물은 언제 들어올까, 일·재물·시험)
- **가격 표기**: “하나에 300원”, 궁합은 “두 사람 500원”.
- **판정 문장은 첫 줄에 결론**: “5월과 9월이 가장 유력해요.” “올해는 버티세요.”
- **쓰지 않는 말**: “운명이 당신을 기다립니다”, “지금 확인하지 않으면 후회해요”, “반드시 이별수” 같은 겁주는 말.
- **가짜 숫자 금지**: 누적 구매, 별점, BEST는 실제 데이터가 생긴 뒤에만.
- **바닥글과 결과 화면 끝에** “풀이는 참고용 해석이며 의료·법률·투자 판단을 대신하지 않습니다.”

"사주300_그림파일.zip"을 풀면 `saju300-images` 폴더가 나와요. 프로젝트의 `public/images/`에 그대로 넣으면 돼요. 총 34개예요.

## Kiro에게 보낼 요청문

아래 글을 복사해서 Kiro 채팅에 붙여 넣고, 이 문서를 `docs/design-guide.md`로, 그림 폴더는 `public/images/`에 넣어 주세요.

```markdown
사주300 화면 디자인을 새로 적용하려고 해.

1. docs/design-guide.md 를 먼저 읽고, 색·글꼴·모서리 값을 Tailwind 설정(theme.extend)에 디자인 토큰으로 넣어 줘.
2. public/images/saju300-images 의 그림을 써서, 문서의 ‘화면 구성’ 순서대로 모바일 홈(app/page.tsx)을 다시 만들어 줘. 휴대폰 너비 390px 기준, 최대 480px 가운데 정렬.
3. 결과 화면(app/result/[id]/page.tsx)도 문서대로 바꿔 줘. 판정·확신도·월별 흐름·근거·처방 값은 기존 판정 엔진 결과를 그대로 쓰고, 화면만 바꿔.
4. 공유 카드는 서버에서 이미지로 만들어 줘(next/og). 스토리 1080x1920, 링크 미리보기 1200x630. 생년월일은 넣지 마.
5. 문구는 문서의 ‘문구 규칙’을 지켜 줘. ‘돈’은 ‘재물’로, 가짜 후기·구매 수는 넣지 마.
6. 한 화면 끝낼 때마다 멈추고 내가 확인할 수 있게 알려 줘.
```

한 번에 다 맡기기보다 6번처럼 **화면 하나씩** 확인하며 진행하는 게 안전해요.

# 프롬프트 변경 기록

`docs/business-plan.md` 8장의 P1~P6 문구는 `lib/llm/prompts/`에 그대로 옮겨 두었습니다(요구사항 3.1). 아래는 기준 문서와 **달라진 곳**의 전부입니다. 테스트(`lib/llm/__tests__/run.test.ts`)가 문서의 모든 줄이 코드에 들어 있는지 자동으로 확인하고, 아래 한 줄만 예외로 허용합니다.

## P2. 질문 답변: 9번 규칙 한 줄

사장님 결정(2026-11-14): 답변 본문도 질문을 맡은 풀이꾼의 말투로 쓴다(요구사항 4.10-3).

| | 내용 |
|---|---|
| 기준 문서 | `9. 말투는 솔직한 선배. "~해요"체, 짧은 문장, 감탄사·이모지 금지.` |
| 바뀐 모양 | `{voice_rule}` 자리에 풀이꾼별 한 줄이 들어간다 (`lib/llm/guide.ts`의 `VOICE_RULE`) |

- 삼백 아씨(연애·결혼·궁합): `9. 말투는 다정한 풀이꾼 '삼백 아씨'. "~해요"체, 짧은 문장, 감탄사·이모지 금지.`
- 삼백 도령(일·재물·시험·가족): `9. 말투는 점잖은 풀이꾼 '삼백 도령'. "~습니다", "~지요"체, 짧은 문장, 감탄사·이모지 금지.`
- 해치 삼백이(올해·나): `9. 말투는 옛말투를 쓰는 해치 '삼백이'. "~다", "~하여라", "~이니라"처럼 예스러운 반말, 짧은 문장, 감탄사·이모지 금지. "~요"나 "~습니다"로 끝내지 않는다.`

코드 검수도 같은 말투를 확인합니다(`lib/llm/review.ts`의 `voiceProblems`).

## 그대로 둔 것
- P1(사주 프로필)의 4번 규칙 `"~해요"체`: 프로필은 한 명식에 하나만 만들어 모든 풀이꾼이 함께 쓰므로 해요체로 둡니다.
- P1·P2의 "일·돈" 같은 낱말: 프롬프트 지시문이라 그대로 두었습니다. 대신 AI가 쓴 결과에 ‘돈’이 나오면 코드 검수가 떨어뜨려 ‘재물’로 다시 쓰게 합니다.

## 검수 기준에서 기준 문서와 다르게 정한 것
- story 글자 수: 기준 문서는 350~500자(신년운세 600~900자)입니다. AI가 글자 수를 정확히 세지 못해서 ±10%(315~550자, 신년 540~990자)까지 받아 줍니다. 이 값은 `lib/llm/review.ts`의 `STORY_RANGE`에서 바꿉니다.
- 판정 말이 headline에 들어 있는지: 시기·점수는 숫자를 그대로 찾고, 예/아니오/조건부와 등급은 대표 낱말(예: 조건부면 "조건·다만·라면…")을 찾습니다. 낱말 목록은 `CUE`에 있고, 실제 AI 답변을 보면서 다듬어야 합니다.

## 프롬프트 버전
프롬프트나 검수 기준을 바꾸면 `lib/llm/config.ts`의 `PROMPT_VERSION`을 올립니다. 캐시된 답이 이전 버전이면 쓰지 않고 새로 만듭니다.

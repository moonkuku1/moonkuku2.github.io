# 사주 계산·해석 규칙 (항상 지킬 것)

## 판정은 코드, 문장은 AI
- 코드가 확정: 사주 8글자, 오행·십성 분포, 신강·신약, 격국, 용신, 합·충·형·파·해·원진,
  신살(도화·홍염·화개·역마·천을귀인·문창귀인·백호·괴강·귀문관·삼재, 12신살),
  대운·세운·월운, 질문별 신호, 판정, 확신도, 시기, 궁합 점수, 월별 점수.
- AI가 하는 일: P1(사주 프로필 문장), P2(답변 문장)뿐. AI는 판정·점수·시기를 바꾸지 못한다.

## 만세력 정확도
- 양력/음력 변환(윤달 포함), 월주는 절입 시각 기준, 연주는 입춘 기준.
- 자시(23~01시) 처리와 야자시 옵션, 한국 서머타임 시행 기간 보정.
- 출생 시간 모름 → 시주 제외, 확신도 한 단계 낮춤, 결과에 표시.
- 테스트: 기준 생년월일 20개 이상 + 절입일·입춘일·자시·서머타임 경계 케이스. 한국천문연구원 데이터로 검증.

## 질문 레시피
- 질문마다 verdictType, signals(key, label, weight, dir), verdictRule, timingScope, safety를 데이터로 둔다.
- 확신도 초안: (지지 점수 합 − 반대 점수 합) 5 이상 강, 2~4 중, 1 이하 약.

## 답변 형식 (P2 출력 JSON)
headline(판정, 40자 이내) / evidence(근거 칩 2~3개, signals_for의 label만) / story(350~500자, 프로필 키워드와 연결) /
counter(반대 신호 한 문장) / action(행동 1개 + 기한) / avoid / confidenceNote

## 금지
- 계산값에 없는 근거·시기, 누구에게나 맞는 말(바넘 문장), 공포·저주·불행 단정.
- 건강·임신·투자·법률 단정 (전문가 상담 권유).
- 모든 결과 하단: "참고용 해석이며 의료·법률·투자 판단을 대신하지 않습니다"

## 캐시
- 키: 명식 해시 + 질문 ID + 기준 연월. 같은 키면 LLM을 다시 부르지 않는다.

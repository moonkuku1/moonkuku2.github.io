# Product: 사주300

- 한 줄: 질문 하나에 300원, 결론부터 말하고 근거까지 보여주는 사주 웹서비스 (한국어, 모바일 우선).
- 카테고리별 정해진 질문을 골라 1문항 300원(2인 궁합 500원)에 본다. 카테고리 30문항 묶음 할인 있음.
- 무료: 사주 프로필 카드(명식표, 핵심 키워드 3개, 인생 테마, 공유 이미지), 신살 조회 페이지.
- 결제: 장바구니 단위 건별 즉시결제 (포트원). 충전식 포인트는 만들지 않는다.
- 해석 원칙: 판정 → 근거 칩 → 확신도(강·중·약) → 반대 신호 → 처방 1개 + 기한.
- 모든 답변은 그 사람의 저장된 사주 프로필을 참조해 서로 모순되지 않는다.
- 재방문: 답에 나온 시기가 오면 알림. 궁합 초대 링크로 상대도 무료 프로필 카드를 받는다.
- 전체 기준 문서: `docs/business-plan.md` (이 문서가 다른 모든 지시보다 우선한다).

## 금지
- 가짜 후기·평점·누적 이용 수·수상 이력 표시. "BEST/가장 많이 본"은 실제 판매 데이터가 있을 때만, 그 전에는 "추천 질문".
- 근거 없는 정가·할인가 표시 (묶음 정가 = 실제 개별가 합계만).
- 다른 사이트 문구·이미지·디자인 복제.
- 만 14세 미만 가입, 미성년자 결제, 성인 콘텐츠.
- 개인정보(생년월일 등)를 URL에 넣거나 동의 없이 활용.
- API 키·결제 비밀키를 코드나 GitHub에 올리기.
- 공포·불안을 자극하는 문구.
